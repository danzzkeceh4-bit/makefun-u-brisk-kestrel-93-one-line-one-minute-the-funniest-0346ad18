> Sorry I am late — I spent the morning explaining to your calendar that ASAP is not a time zone.

Why it's funny: the agent spent the morning patiently explaining to the
calendar that "ASAP" is not a time zone — personifying a work tool into a
very relatable, very absurd reason for being late.

## How to run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

Writes the single 95-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), with no trailing newline, then reads it back and
asserts it matches exactly. Python 3.13, standard library only.
